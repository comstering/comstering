### 👋 Hi there, I'm Hansu Choi (comstering)

**DevOps · Cloud Native Engineer**

I narrow the gap between development and operations so teams can focus on business logic, not infrastructure.
I started as a backend engineer (Kotlin · Spring Boot) and now build the platform those services run on.

### 🧰 What I do

- ☸️ **Kubernetes platform** — EKS with Karpenter, Istio ambient mesh, Cilium (eBPF), and Operators for stateful components
- 🏗️ **Infrastructure as Code** — AWS and Cloudflare managed with Terraform modules, deployed through GitOps (Argo CD)
- 🔄 **CI/CD · Workflow** — GitHub Actions (ARC), Argo Workflows, and self-hosted Temporal
- 🔐 **Identity · Zero Trust** — Keycloak, Okta SSO, OAuth2 Proxy, and Istio authorization policies
- 📨 **Event streaming** — Kafka, Kafka Connect, Debezium CDC, and Schema Registry on Kubernetes
- 📝 **Writing** — I only write about what I've actually run: [comstering.github.io](https://comstering.github.io)
